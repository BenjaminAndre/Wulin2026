# Conséquences

*Un jet raté a un prix. L'annoncer AVANT de lancer les dés aide à le faire payer : « si tu rates, … ». Choisir celle qui convient le mieux à la fiction, ou la lancer.*

- Blessure : un coup porte, il laisse une trace
- Blessure : un muscle froissé, une technique devient douloureuse
- Épuisement : le souffle, le qi, ne revient pas tout de suite
- Arme perdue, brisée ou tombée hors de portée
- Objet perdu : la bourse, la lettre ou le jeton
- Argent : il faut payer, soudoyer ou rembourser
- Temps perdu : l'adversaire avance pendant ce temps
- Retard : on arrive après l'événement
- Séparation : le groupe se retrouve divisé
- Capture : quelqu'un est pris, peut-être un PJ
- Témoin : quelqu'un a vu, et le dira
- Réputation : le nom des PJ circule, et pas en bien
- Face perdue : une humiliation publique
- Dette : quelqu'un les a aidés, et s'en souviendra
- Ennemi : un PNJ neutre devient hostile
- Escalade : des renforts arrivent
- Alerte : les autorités sont prévenues
- La cible fuit ou se cache
- Un allié est blessé, ou mis en danger
- Un innocent paie à leur place
- Le plan est éventé
- Une promesse est rompue malgré eux
- Une piste s'efface
- Un secret des PJ est révélé
- Le lieu devient dangereux : feu, effondrement, inondation
- Ils obtiennent ce qu'ils voulaient, mais faux ou incomplet
- Un serment les lie désormais
- Un poison, une maladie ou une malédiction s'installe
- Leur position est perdue : ils sont acculés
- Un choix difficile s'impose : sauver l'un ou l'autre
